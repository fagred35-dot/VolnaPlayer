# 🌊 Волна — сборка под Windows

Лёгкий музыкальный плеер. UI на React + Vite + Tailwind, аудио — Web Audio API, файлы из выбранной папки отдаются через собственный протокол `volna://` (с поддержкой Range-запросов — перемотка работает мгновенно, без загрузки файла в память).

## Возможности

- **Папка-источник**: нативный диалог выбора папки → все треки подтягиваются автоматически (рекурсивно, до 5000 файлов), читаются настоящие теги: название, исполнитель, альбом, длительность, встроенная обложка (music-metadata)
- Авто-синхронизация при запуске + кнопка «Синхронизация» (новые/изменённые/удалённые файлы); избранное папочных треков сохраняется между перезапусками
- Обложки: из тегов файла (кэшируются на диск и переживают перезапуск) → iTunes/Deezer по названию → красивый градиент
- **Громкость каждого трека** — своё усиление (0–100%), кнопка с процентами в плеере и слайдер в «Сейчас играет»; запоминается для каждого трека
- Эквалайзер 10 полос, таймер сна, визуализатор, избранное, поиск, горячие клавиши
- **Скачивание музыки** (yt-dlp): по ссылке или поиском на YouTube, очередь строго по одному, конвертация в MP3 через FFmpeg. Исполняемые файлы (yt-dlp / Node.js / FFmpeg) скачиваются **пиннутых версий с проверкой sha256** — манифест `RUNTIMES` в `electron/main.js`, обновление версий = правка манифеста
- **Темы и стили**: 10 готовых тем, свои обои (PNG/JPG/**анимированные GIF**), редактор CSS-кода, прозрачное окно + Acrylic/Mica (Windows 11)
- **Мини-плеер (оверлей)** — frameless-окно поверх всех: 4 пресета вида, прозрачный фон, режим перемещения (Ctrl+Alt+M), позиция и размер запоминаются
- **Недавние + статистика**, альбомный вид, плейлисты, очередь воспроизведения, адаптивный UI

## Сборка .exe

```bash
# 1. Собрать сайт (в корне проекта)
npm install
npm run build

# 2. Собрать Windows-приложение
cd electron
npm install
npm run build
```

Готовый установщик: `electron/release/Волна Setup 1.3.1.exe`

Быстрый запуск окна без установки: `cd electron && npm start`, либо из корня: `npm run app` (сайт в `dist/` должен быть собран).

**Разработка фронтенда с hot-reload:** запустите `npm run dev` (Vite на :5173) и во втором терминале `cd electron`, затем:
```bash
# PowerShell
$env:VITE_DEV_SERVER_URL = "http://localhost:5173"; npm start
```
При заданном `VITE_DEV_SERVER_URL` окна грузят dev-сервер в приоритете (иначе — собранный `electron/dist`).

**Проверки качества:**
```bash
npm run lint   # ESLint (typescript-eslint + react-hooks)
npm test       # Vitest: lib/format, lib/art, очередь загрузок
npx tsc --noEmit
```
CI (`.github/workflows/ci.yml`): tsc + lint + тесты + build + `npm audit --omit=dev` для обоих пакетов.

**Если npm тормозит с electron:**
```bash
npm config set electron_mirror https://npmmirror.com/mirrors/electron/
```

## Как это устроено (важно для отладки)

| Что | Как |
|---|---|
| Выбор папки | `ipcMain.handle("pick-folder")` → `dialog.showOpenDialog` + рекурсивный обход (`walk`, лимит 5000 + флаг `truncated`) |
| Воспроизведение из папки | протокол `volna://local/<путь>` — только для разрешённых корней (сравнение путей case-insensitive), Range-запросы (206/416, суффикс `bytes=-N`) |
| Обложки из тегов | `music-metadata` в main-процессе, отдаются по `volna://cover/<hash>`; hash валидируется (`^[0-9a-f]{1,16}$`) |
| Скачивание | `dl-download` → yt-dlp (очередь в рендерере, `useDownloadQueue`); загрузка бинарников — `downloadFile` (`.part` + sha256 + idle-timeout 30 c + 3 ретрая); автозапуск `-U` у yt-dlp не чаще раза в сутки |
| Безопасность | CSP в `index.html`, `will-navigate` запрещён, `contextIsolation` + без `nodeIntegration`; `destDir` скачивания — только внутри разрешённых корней |
| Данные | IndexedDB в профиле приложения; корни папок — `userData/volna-roots.json`; избранное папочных треков — meta `favs`; тесты — `tests/` (Vitest) |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | play / pause |
| `←` `→` | перемотка ±5 сек |
| `↑` `↓` | громкость |
| `M` | mute |
| `N` / `P` | следующий / предыдущий |
| `Ctrl+O` / `Ctrl+K` | добавить файлы / поиск |
| `Ctrl+Alt+M` | режим перемещения оверлея |
| Медиа-клавиши | play/next/prev (MediaSession) |

## Если что-то не работает

1. `Ctrl+Shift+I` → Console: посмотрите ошибки
2. «Выбрать папку» не находит файлы → проверьте, что папка не пустая и не системная; для папок >5000 треков библиотека обрезается (тост-предупреждение)
3. Обложки не грузятся → возможно, нет интернета; обложки из тегов работают офлайн
4. Скачивание не стартует → первый запуск докачивает yt-dlp/Node/FFmpeg в `userData`; если скачанный файл не проходит sha256 — он удаляется и скачивается заново
5. Пришлите текст ошибки — разберём

## Известные отложенные задачи

- **Electron 33** (Chromium ~130, окт 2024) — ветка вне окна поддержки; при обновлении проверить прозрачное окно, Acrylic/Mica (`setBackgroundMaterial`), `titleBarOverlay` и мини-плеер
- **music-metadata v7** — advisory file-type (ASF infinite loop) в prod-зависимостях; v11 требует ESM-миграции main.js
- **Виртуализация плейлиста** — список рендерит все строки (memo есть, окна нет); заметно при 1000+ треков
