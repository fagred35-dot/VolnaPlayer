# 🌊 Волна — сборка под Windows

Лёгкий музыкальный плеер. UI на React + Vite + Tailwind, аудио — Web Audio API, файлы из выбранной папки отдаются через собственный протокол `volna://` (с поддержкой Range-запросов — перемотка работает мгновенно, без загрузки файла в память).

## Возможности

- **Папка-источник**: нативный диалог выбора папки → все треки подтягиваются автоматически (рекурсивно), читаются настоящие теги: название, исполнитель, альбом, длительность, встроенная обложка (music-metadata)
- Авто-синхронизация при запуске + кнопка «Синхронизация» (новые/изменённые/удалённые файлы)
- Обложки: из тегов файла (кэшируются на диск и переживают перезапуск) → iTunes/Deezer по названию → красивый градиент
- **Громкость каждого трека** — своё усиление (0–200%), кнопка с процентами в плеере и слайдер в «Сейчас играет»; запоминается для каждого трека
- Эквалайзер 10 полос, таймер сна, визуализатор, избранное, поиск, горячие клавиши
- **Темы и стили** (сайдбар → «Темы и стили»): 10 готовых тем, свои обои (PNG/JPG/**анимированные GIF** — оживают в фоне, по файлу или ссылке, с затемнением и размытием) и **редактор CSS-кода** — вписал CSS → UI полностью твой. Все цвета UI — через CSS-переменные (`--accent`, `--bg-base`, `--t1..3`, `--surface`, `--panel`, `--line` и др.), свой CSS применяется мгновенно и перебивает темы
- **Мини-плеер** — кнопка в нижней панели сворачивает окно в маленький frameless-плеер поверх всех окон (обложка, назад/плей/вперёд, крестик при наведении разворачивает обратно). Музыка не прерывается. Темы/обои синхронизируются с основным окном автоматически
- **Недавние + статистика** — раздел «Недавние» (30 последних треков) и «Статистика» (прослушивания, время в музыке, чаще всего, недавние)
- **Альбомный вид** — кнопка в шапке переключает список ↔ сетка альбомов (по тегам), клик по альбому открывает его треки
- Адаптивный UI: при уменьшении окна сайдбар превращается в выдвижное меню, часть кнопок прячется

## Сборка .exe

```bash
# 1. Собрать сайт (в корне проекта)
npm install
npm run build

# 2. Собрать Windows-приложение
cd electron
npm install
npm run build
```

Готовый установщик: `electron/release/Волна Setup 1.1.0.exe`

Быстрый запуск окна без установки: `cd electron && npm start` (сайт в `dist/` должен быть собран).

**Если npm тормозит с electron:**
```bash
npm config set electron_mirror https://npmmirror.com/mirrors/electron/
```

## Как это устроено (важно для отладки)

| Что | Как |
|---|---|
| Выбор папки | `ipcMain.handle("pick-folder")` → `dialog.showOpenDialog` + рекурсивный обход |
| Воспроизведение из папки | протокол `volna://local/<путь>` — только для разрешённых корней, Range-запросы (206) |
| Обложки из тегов | `music-metadata` в main-процессе, отдаются по `volna://cover/<hash>` |
| Теги | кэш в памяти main-процесса; при сканировании запрашиваются только новые/изменённые файлы |
| Тексты | textyl.co (синхронные) → lyrics.ovh (просто текст) → свой текст в IndexedDB |
| Данные | IndexedDB в профиле приложения; корни папок — `userData/volna-roots.json` |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | play / pause |
| `←` `→` | перемотка ±5 сек |
| `↑` `↓` | громкость |
| `M` | mute |
| `N` / `P` | следующий / предыдущий |
| `Ctrl+O` / `Ctrl+K` | добавить файлы / поиск |
| Медиа-клавиши | play/next/prev (MediaSession) |

## Если что-то не работает

1. `Ctrl+Shift+I` → Console: посмотрите ошибки
2. «Выбрать папку» не находит файлы → проверьте, что папка не пустая и не системная
3. Тексты/обложки не грузятся → возможно, нет интернета; обложки из тегов работают офлайн
4. Пришлите текст ошибки — разберём
